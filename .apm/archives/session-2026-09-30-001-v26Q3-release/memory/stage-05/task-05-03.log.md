# Task 5.3 - Art Assets (follow-up — three candidates, cup fixes)

## Summary
`scripts/generate_art.py` now takes `--out` and generates three
design candidates each for the app icon, banner and avatar (nine
PNGs total) into the User's review folder. Candidate 1 fixes the
handle-gap and saucer-seating issues from the previous pass; candidates
2 and 3 are new, distinct compositions. Returning Partial for the
User's pick, per the Task Prompt.

## Details
- Read `scripts/generate_art.py` in full before editing.
- Refactored the unit-square → pixel mapping (`pt`/`rect`) into a
  shared `_unit_mappers()` helper so all three scene functions and the
  steam-curl helper (`_draw_steam()`) can reuse it without duplicating
  the closure.
- **Candidate 1 (`draw_cup_saucer_scene`)** — same cup-and-saucer idea
  as the reviewed design, with the two requested fixes:
  - Handle: the arc's bounding box is now centered on the cup body's
    right edge (`ux=0.78`) instead of starting to the right of it, so
    both arc endpoints land just inside the cup body — no visible gap.
  - Saucer: the cup body's base was extended down (`uy 0.74 → 0.76`)
    and the saucer's top was raised (`uy 0.74 → 0.70`), so the cup
    base now overlaps the saucer ellipse by a clear margin instead of
    barely touching it. Saucer is still drawn first (behind the cup).
- **Candidate 2 (`draw_kettle_pour_scene`)** — new idea: a kettle
  (rounded-rectangle body, lid knob, arc handle attached to the body
  the same way as fix 1) with a triangular spout pouring an amber
  stream into a smaller cup-and-saucer at lower right, with two steam
  curls above the small cup.
- **Candidate 3 (`draw_monoline_badge_scene`)** — new idea: a
  monoline (outline-only) teacup mark inside a circular badge ring, on
  a dark steeping-forest background instead of the light sage tint,
  with a light-tint wordmark for the banner. Distinct technique (line
  art vs. flat fill) and mood (dark ground) from candidates 1 and 2.
- Introduced a small `Candidate` class bundling each design's
  background, scene function, per-surface `content_scale` (icon /
  avatar / banner), and text color; `generate_all()` loops over the
  three `CANDIDATES` to emit all nine files. Avatars use a larger
  `content_scale` than icons per the avatar-specific instruction
  (tighter crop / larger subject), while staying inside the ~80%
  diameter safe circle.
- Added `argparse` with `--out` (default `<repo root>/.debug-images`).
- Removed `assets/app-icon.png`, `assets/app-banner.png`,
  `assets/avatar.png` via `git rm` — the User will place chosen
  finalists there as `app-icon.png`, `app-banner.png`,
  `app-avatar.png`.
- Updated the module docstring to describe the `--out` flag and the
  three candidate ideas.
- Generated the nine candidates into
  `/home/jfang/WSL/github.com/jonathan-fang/teamode/.debug-images/`.
  Verified no existing file there (`.gitkeep`, `hello.md`, `keep/`,
  the previous `app-icon.png`/`app-banner.png`/`avatar.png`) was
