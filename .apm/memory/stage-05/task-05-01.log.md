# Task 5.1 - /teamode-stats

## Summary
Added `/teamode-stats`, an ephemeral embed showing sessions, focus
minutes, completion rate and a personal streak for "You" and "This
server" over 7 days, 30 days and all time.

## Details
- Read `app/db.py`, `app/config.py`, `app/timer_format.py`,
  `app/discord_bot/clear.py`/`client.py`, the committed
  `app/constants.py` `STATS_*` block, `app/discord_bot/views.py`
  `COLORS`, and `tests/test_db.py` / `tests/test_bot_clear.py` for
  patterns before writing anything.
- Added two read helpers to `app/db.py`:
  `fetch_facilitator_stats_rows` and `fetch_guild_stats_rows`, both
  filtered to `status IN ('completed', 'followup_timeout')` and
  returning a new `StatsSessionRow` dataclass (`started_at`,
  `duration_minutes`, `completed_intention`). The facilitator helper
  filters on `facilitator_id` only (never `handoff_facilitator_id`).
- Added `app/stats.py`, a pure module (no `discord` import) with:
  `compute_window_stats` / `compute_stats_summary` (7-day, 30-day,
  all-time — window lengths from `STATS_WINDOWS_DAYS`), `compute_streak`
  (consecutive local calendar days in a given `tzinfo`, ending today or
  yesterday), and rendering helpers (`render_sessions_text`,
  `render_row_value`, `render_streak_line`, `render_section_value`)
  built only from `app.constants` strings.
- Added `app/discord_bot/stats.py` (`StatsMixin`), following the
  `ClearMixin` pattern: `_register_stats_command` registers
  `/teamode-stats` on `self.tree`; `_handle_stats` guards on
  `interaction.guild_id is None` (→ `MSG_WRONG_CHANNEL`), fetches rows
  for the invoker and the guild, and renders either `STATS_EMPTY` (both
  all-time totals are 0) or a two-field embed (`STATS_SECTION_YOU`
  with the streak line appended, `STATS_SECTION_SERVER`).
- Wired `StatsMixin` into `TeaModeBot` in `app/discord_bot/client.py`
  and called `_register_stats_command()` in `__init__`.
- Added `tests/test_stats.py` covering: only completed/followup_timeout
  rows counted; original-facilitator-only credit (handoff target
  excluded); guild filtering; 7d/30d/all-time window filtering;
  NULL `duration_minutes` treated as 0; completion rate as
  ✅/(✅+⛔), undefined when that denominator is 0 (renders
  `STATS_ROW_VALUE_NO_RATE`); singular sessions/streak copy; streak
  hidden at 0; streak over consecutive local days ending today or
  yesterday, including a case that crosses UTC midnight but not local
  midnight (`America/Los_Angeles`); empty-data embed; and the command
  responding ephemerally with a `STATS_TITLE` embed, a no-guild
  refusal, and correct field names/inline flags.
